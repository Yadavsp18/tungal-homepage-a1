# Photos

Drop authentic Tungal photographs here (WebP, about 1600 px wide for hero and campus slots, 1000 px for cards and gallery),
then register each one in `assets/js/site-data.js` under `photos`, for example:

    'campus-hulyal': { src: 'assets/photos/campus-hulyal.webp', alt: 'Hulyal campus main building' },

Until a slot is registered, its brand illustration shows, so the page never has an empty or broken image.
Do not use stock photos of other schools, and do not use generated people as Tungal students.
